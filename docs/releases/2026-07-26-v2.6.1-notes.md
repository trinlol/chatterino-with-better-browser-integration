# Chatterino Better Browser 2.6.1

## Highlights

This patch release fixes the chat input and pinned-announcement behavior found during live Twitch use. It also consolidates recent browser-integration reliability fixes so chat, predictions, and emote completion remain responsive as Twitch tabs and windows change state.

## Upgrade Notes

- Extract the complete Windows package rather than running the EXE by itself; the included Qt runtime files are required.
- Reload the bundled unpacked browser extension after upgrading.

## At a Glance

| Product Area | Changed | Fixed |
|---|---:|---:|
| Chat input and emotes | 0 | 2 |
| Pinned announcements | 1 | 1 |
| Twitch browser integration | 1 | 3 |

## Product Areas

### Chat Input and Emotes

- Fixed: Enter and Return send the current message instead of adding an unwanted new line.
- Fixed: 7TV-only completion and the related-emote popup work consistently in the input box.

### Pinned Announcements

- Changed: HTTP, HTTPS, and `www.` links are clickable and open externally.
- Fixed: closing a pin stays effective when Twitch repeatedly rebinds the same channel and message.

### Twitch Browser Integration

- Changed: prediction voting controls remain accessible beside the player.
- Fixed: prediction countdowns continue updating instead of becoming stuck.
- Fixed: attached chat follows browser moves and maximize/restore transitions without trailing behind.
- Fixed: attached chat remains connected while the Twitch window is inactive.

## Known Issues

- No release-blocking known issues.
