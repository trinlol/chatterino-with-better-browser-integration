# Chatterino Better Browser 2.6.2

## Highlights

This patch fixes the Twitch chat overlay failing to connect until the browser
extension is reloaded. Chatterino and its native browser host now announce when
they are ready, allowing the active Twitch tab to resend its chat position
automatically regardless of startup order.

## Upgrade Notes

- Extract the complete Windows package rather than running the EXE by itself;
  the included Qt runtime files are required.
- Reload the bundled unpacked extension once after upgrading to activate the
  new background worker. Future startup-order recovery is automatic.
